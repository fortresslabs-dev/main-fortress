Section 03 · Reading the gap types

Two distinct failure modes

◆ Note
No control mapped = a regulatory obligation with no control assigned (a program design gap). Mapped · not tested / partial = a control exists but lacks a passing test or full evidence (an execution gap). Each is linked to a remediation reference — either an open finding (F-…) or a planned test (MDP-…).
