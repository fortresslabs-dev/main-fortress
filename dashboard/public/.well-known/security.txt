# Reporting guidance
# ──────────────────
# Please include in your report:
#   - Affected URL or endpoint (e.g. dashboard.{bank}.com, api.fortresslabs.dev, fortressapi.{bank}.com)
#   - Steps to reproduce, including any payloads
#   - Impact assessment
#   - Whether you intend public disclosure, and your preferred timeline
#
# Initial acknowledgement SLA: 24 hours.
# We commit to a coordinated-disclosure timeline of 90 days for non-critical
# findings, or sooner by mutual agreement. Active exploitation gets escalated
# to the on-call rotation immediately.
#
# We do NOT currently operate a paid bug bounty. Recognition on
# /security/acknowledgements is offered for valid, novel findings.
#
# Per AWS Marketplace customer expectations, all security findings affecting
# bank-deployed Pipeline 2 stacks are remediated in the CloudFormation
# templates we publish; banks pull updates on next deploy.
