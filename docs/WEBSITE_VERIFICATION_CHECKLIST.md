## 🚨 **RED FLAGS TO WATCH FOR**

### **Technical Red Flags:**
```
□ Claiming features not yet built
□ Inaccurate performance metrics
□ Overpromising capabilities
□ Missing important caveats
```

### **Legal/Compliance Red Flags:**
```
□ Absolute claims ("zero errors")
□ Unverified regulatory deadlines
□ Misleading compliance coverage
□ Missing required disclaimers
```

### **Marketing Red Flags:**
```
□ Too technical for executives
□ Too simple for engineers
□ Unclear value proposition
□ Weak differentiation
```
