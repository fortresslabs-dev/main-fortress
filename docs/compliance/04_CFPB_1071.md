# Source 4: CFPB Section 1071 — Small Business Lending Data Collection

## What We Are Targeting

Extract **Section 1071 data collection rules** from the Consumer Financial Protection Bureau covering:
- 88 required data points for small business loan applications
- Demographic data: race, sex, ethnicity of up to 4 principal owners
- Compliance tiers (Tier 1: Jul 2026, Tier 2: Jul 2027, Tier 3: Jul 2028)
- Loan amount threshold ($5M)
- "I do not wish to provide" opt-out rules
- Firewall requirements (demographic data cannot influence underwriting)

**Test cases:** 4 (TC-019 → TC-022) — 11% of all test cases
**URGENT:** Tier 1 compliance deadline is **July 1, 2026** (4 months away)

## Implementation Plan

### Step 1: Scrape the Implementation Guide (HTML — no AI)

The CFPB implementation guide is a well-structured HTML page with numbered data points. Parse with BeautifulSoup.

```
Tool: requests + BeautifulSoup
Input: Implementation guide URL
Output: Structured list of 88 data points with field names, types, options
Cost: $0
```

### Step 2: Extract compliance tier deadlines (HTML — no AI)

Tier definitions and deadlines are on the final rule page. Simple HTML parsing.

```
Tool: requests + BeautifulSoup
Input: Final rule page URL
Output: 3 tier definitions with origination thresholds and dates
Cost: $0
```

### Step 3: Extract detailed field specs from Federal Register PDF (AI needed)

The 88 data points have detailed validation rules, options, and edge cases in the Federal Register publication. This is a large PDF that needs LLM extraction.

```
Tool: pdfplumber (text extraction) + Claude Sonnet 4 (structured parsing)
Input: Federal Register PDF → extract fields 1-88 with types, options, validation rules
Output: JSON array of 88 data point definitions
Cost: ~$0.50-1.00 in Anthropic tokens (large PDF, ~200 pages relevant)
```

### Step 4: Build connector with structured rules

Combine HTML-scraped data with PDF-extracted details. Code the 4 test scenarios.
